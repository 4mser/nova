Each crew member, their own app connected to the ship

The NOVA app has a mission mode. With the ship address and the seat (T1 to T4) set, the phone stops using cloud services and talks only to the ship link over the local network. It uses the same data contract as the medical station, so to the core a phone is just one more station.
