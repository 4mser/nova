A single program starts and watches everything else

NOVA PC (Tauri, with its link in Rust) is the only thing to open. Once it starts, with or without a window, it brings up the seven on-board services, checks them every 3 seconds and restarts any that crashes. What is already running is not duplicated and each service writes its log to ~/.nova-pc/logs/.

The link: two doors and a single API

  HTTP :8750

Screens, phones and Earth console. Serves the interface and the API; every response carries no-cache, so the screen always loads the new version.

  HTTPS :8751

The same app with its own certificate (rcgen + rustls), since the browser grants the camera only to secure pages. It includes today's IPs and is rebuilt if they change.

  Optional token

With NOVA_TOKEN, the 8 routes that write from outside (phones, viewers, Earth, Home) require the header x-nova-token.
