Memory in use, measured

Resident memory of each process. Total near 4.1 GB: fits in an 8 GB flight computer with margin.

Fast where it matters

Rules and protocols go first in the prompt: with the prefix cache NOVA starts answering in about 1.5 s. Vision takes about 13 ms per frame.

What the models don't do

They do not decide medical steps or thresholds. Emergencies answer with fixed text: the model once denied a reported arrest because the sensor did not show it.

Optional demo, declared

For the demo the brain can be Claude; the screen says “demo brain · Claude” and falls back to the on-board model on its own. It stays outside the flight architecture.
