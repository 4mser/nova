One command and the ship is running

Since November 14 the ship starts and watches everything it needs on its own. What already runs is not duplicated, what crashes is restarted and each service writes its log to ~/.nova-pc/logs/.

# ship window + core, simulator, models, voice, hearing, search and vision
cd tripulacion && npm install && npm run dev
# no window: the link at http://127.0.0.1:8750 and the scanner at https://<ship>:8751/escaner.html
cd tripulacion && npm run enlace
# with Luis's real station, or to start each piece by hand
NOVA_SIN_SIMULADOR=1 npm run enlace
NOVA_SIN_SERVICIOS=1 npm run enlace
# second test ship, without stopping the running one
NOVA_PUERTO_ENLACE=8760 ./src-tauri/target/debug/nova-tripulacion --sin-ventana
# build the flight core (Python 3.12)
git submodule update --init --recursive
cd vuelo && python3.12 -m venv fprime-venv && source fprime-venv/bin/activate
pip install -r requirements.txt && cd Nova/Nave && fprime-util generate && fprime-util build -j

Glossary

F Prime. JPL flight software framework, in C++, Apache 2.0.

GDS. F Prime ground system: telemetry, events and commands.

CCSDS. Space communications standard; frames and packets.

NDJSON. One JSON object per line: how the station talks.

SSE. The link pushes state to the screens without them asking.

ed25519. Digital signature; the ship keeps only the public key.

LBS. Bone blending that deforms the anatomy with the body.

Timewarp. Correcting lag with the phone's gyroscope.

Evetts-Russomano. Microgravity CPR with the legs over the patient's shoulders.

QCPR. CPR quality: rate, depth and pauses.
