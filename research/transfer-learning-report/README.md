Technical LaTeX report on the work in [`../transfer-learning/`](../transfer-learning) (PR #2). If you only want to
read it, open [`informe.pdf`](informe.pdf): 65 pages and 91 references. **The report is in Spanish**; the English
summary of the same work is the [transfer-learning README](../transfer-learning/README.md).

It covers the history of transfer learning and fine-tuning, from Thorndike (1901) to time-series foundation models;
the data (NASA −6° bed rest and LifeSnaps); the two models (expected range and PatchTST forecasting); the results of
the third kernel run; the audit of 14-11-2026; how it would fit into the ship; and the 26 decisions of 14-11. The
connection with the ship is designed, not built, and run v4 is planned, not run. The report says so in each case.

## Build

You need LuaLaTeX, biber and latexmk (MiKTeX or TeX Live), plus the fonts Libertinus Serif, Libertinus Sans,
Libertinus Math and Source Code Pro.

```
latexmk -lualatex informe
```

Everything needed to compile is in this folder, because `generado/` is included.

## Regenerate the figures

No result figure is written by hand in the chapters: all of them come from `generado/cifras.tex` via `\cifra{...}`, or
from a table or plot in `generado/`. They are written by `herramientas/construir_cifras.py`, which reads the `fuentes/`
folder and the code in `../transfer-learning/`:

```
cd herramientas
python construir_cifras.py .. ../../transfer-learning
```

`fuentes/` is not in git, because it holds the complete subject tables and the model weights. This is how it is
assembled:

| File | Where it comes from |
|---|---|
| `metricas.json`, `log.txt`, `rango_esperado*.csv`, `placebo_pre.csv`, `pronostico*.csv`, `desplazamiento_reposo.csv`, `ruido_por_variable.json`, `corrector_poblacion.json` | output of the third run: `kaggle kernels output benjacampos/nova-transfer-learning` |
| `reposo_largo.parquet`, `reposo_covariables.parquet`, `tierra_largo.parquet` | kernel input, prepared with `python -m nova_tl.datos` (see the README in `../transfer-learning/`) |
| `nova-tierra.safetensors`, `nova-espacio.safetensors` | the `model.safetensors` of `Benjjaman/nova-tierra` and `Benjjaman/nova-espacio` on Hugging Face (private for now) |
| `config_patchtst.json` | the PatchTST configuration, in the format of the `config.json` the kernel writes with `save_pretrained` in `pesos/` |
| `datos_auditoria.json` | the script of the 14-11 audit, which is not in the repository |

The sha256 hashes of the input data, the weights and the result files are in the report's reproducibility appendix.

Data from a single person appears in only one place: the figure in chapter 5 (`generado/fig_ilustracion.tex` and the
PDF). It plots the daily weight of one bed-rest subject, identified by their subject code (`C3_6043`), which is the
same kind of code already present in `resultados/metricas.json` in `../transfer-learning/`. If the repository is made
public, that figure needs to be reviewed.

## Bibliography

The references were not written from memory: they come from Crossref, DBLP, OpenAlex, arXiv and Semantic Scholar, with
a matching rule on title, first author and year. The steps are in the reproducibility appendix, and the
`generado/registro_*.tsv` files record which service resolved each key. `resolver_bib2.py` also downloads the abstracts
of the works to `generado/resumenes.json`, which is not committed because it is third-party text.
